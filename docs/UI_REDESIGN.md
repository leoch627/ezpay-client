## 二、连上游收款站的真实协议（已解出）

```json
// settings.json（真实值）
{
  "merchantUrl":    "https://pay.rliyun.cn",
  "merchantId":     "10059",
  "merchantSecret": "",                       // 明文位置留空
  "protectedMerchantSecret": "AQAAANCMnd8BFdERjHoAwE..."  // DPAPI 加密
}
```

上报时的关键差异（相对我之前做的）：

| 项 | 我之前的实现 | 真实做法 |
|---|---|---|
| 密钥存储 | config.json 明文 | **DPAPI 加密**存 `protectedMerchantSecret` |
| 通道选择 | 全局一个 | **按账号绑定** `account_channels.json` |
| 商户ID | 选填 | **必填**，上报必带 |
| 上游地址 | serverUrl | `merchantUrl`，就是你的收款站 |

## 三、重构后的界面

### 3.1 侧栏（7 项 + 客服卡）

| 菜单 | 内容 |
|---|---|
| **总览** | 今日/昨日/累计金额与笔数、回调成功率、监控状态 |
| **微信账号** | 截图这一页（本次重点） |
| **收款记录** | 记录表格，按金额/时间/状态/通道筛选 |
| **通知设置** | 上游商户配置 + SMTP/企微/钉钉 |
| **运行日志** | 日志流（保留现有实现，加级别过滤） |
| **系统设置** | 端口、注入、超时、禁止更新 |
| 底部卡片 | 在线客服 / 反馈 QQ（放占位，不硬编码原程序的号） |

支付宝/QQ 这一版**不做**（你只要微信收款），侧栏不出现。

### 3.2 微信账号页（对照截图逐块实现）

**A. 程序定位条**
- 自动从注册表 `Software\Tencent\Weixin\InstallPath` 找 exe
- 右侧状态：`● 运行中 · PID xxxx`（绿）/ `○ 未运行`（灰）

**B. 账号卡片**
- 大号微信图标（绿底）+ `constant · PID xxxx` + `监听中` 徽章
- 副标题：`wxid_xxx · 64 位微信适配`
- 按钮组：
  - `绑定通道ID` → 弹窗（第三张截图形态）
  - `收款码设置` → 弹窗（第二张截图形态）
  - `立即检测` / `重新注入`

**C. 双栏信息**
- 左：账号资料（微信ID / 微信号 / 手机号，敏感项可"显示"）
- 右：运行信息（微信版本 / **通道ID** / 最后心跳）

**D. 程序检查点**
三张卡：登录状态 / 账号资料 / 消息接收，各带 `● 正常 / ● 异常` 徽章

**E. 绑定通道ID 弹窗**（照第三张截图）
```
绑定通道ID
微信 · wxid_jalj9ys3nz8u12
─────────────────────────
通道ID
[ 6552                    ]
留空保存会取消该账号绑定，未绑定时上报使用默认通道。
                  [保存]  [取消]
```

**F. 收款码设置弹窗**（照第二张截图）
- 左：固定金额收款项列表 + 新增（名称 + 金额元 → 存分）
- 右：当前账号卡 + 在线收款码预览区
- 底部：`取消` / `保存设置`

## 四、数据结构

```jsonc
// data/config.json —— 上游收款站（全局）
{
  "upstreamUrl":    "https://pay.example.com",  // 你的收款站
  "merchantId":     "10059",
  "merchantSecret": "",                          // 空 = 用 protected 里的
  "protectedMerchantSecret": "AQAAANCM...",      // DPAPI blob
  "channel":  "wechat",
  "listenAddr": "127.0.0.1:29731"
}

// data/account_channels.json —— 按账号绑定的通道
{
  "wechat:wxid_jalj9ys3nz8u12": "6552"
}

// data/payment_codes.json —— 固定金额收款项
{
  "wechat:wxid_jalj9ys3nz8u12": [
    { "key": "item_a1", "name": "测试2", "priceCents": 10 }
  ]
}
```

上报时：`channelId = account_channels["wechat:" + wxid]`，没绑定就不带（走上游默认通道）。

## 六、验收

- 截图对照：微信账号页与截图逐块对应（定位条/账号卡/双栏/检查点）
- 两个弹窗可开可关可保存
